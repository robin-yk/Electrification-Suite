Five-minute workflow

How to use this model

Start with the transparent 0D screen, then solve the selected design on a fixed 60 × 60 axisymmetric display mesh. The physical cell size and surrounding-air domain scale automatically with the defined reactor geometry.

1 · Choose a material

Preset or custom
Presets load cited room-temperature data plus temperature interpolation where a source supplies it. You may overwrite every field.

2 · Enter cylindrical geometry

Nominal volume + L/D + void fraction
Nominal volume is the outer L × D envelope. Void fraction φ = 0 is a dense rod; higher φ removes conducting solid from the same envelope.

3 · Define hardware limits

I, V, P and J ceilings
The page chooses the lowest allowed current at each temperature. Jmax is a screening/design limit, not a universal failure constant; assumed presets are marked in Calculations.

4 · Set the thermal case

Ambient, target and enclosure
Single Design uses the same gas gap, wall, surrounding-air domain, end condition, gap radiation, and 50 sccm He inlet defined for the 2D field.

5 · Read the flags

Feasibility and Biot screening
“Feasible” means the source can balance modeled heat loss at target. Bi ≤ the selected limit supports a lumped-temperature approximation; it does not prove local uniformity in a porous body.

6 · Solve the 2D field

Current design → axisymmetric mesh
The 2D tab reuses the selected material, calculated L and D, porosity, temperature-dependent properties, and all four power-supply limits. Add only enclosure and end-boundary data.

7 · Compare and audit

Compare → Sweep → Calculations
Material Compare provides a fast 0D screen, the sweep checks resistivity and geometry sensitivity, and Calculations contains the equations, assumptions, substituted values, and exact JavaScript.

Initial Ramp Rate vs Resistivity

Electrical Power vs Resistance

Peak power gives peak initial ramp
Why the default peak is near R = 5 Ω: below 5 Ω, I = 20 A and P = I²R, so increasing R raises power. Above 5 Ω, V = 100 V and P = V²/R, so increasing R lowers power. At R = Vmax/Imax = 5 Ω, P = IV = 2,000 W, and P/Vsolid (and therefore the initial ramp rate) reaches its maximum.

Low resistance

P = Icap²R ↑
Current is already at its ceiling. More resistance converts the same current into more heat.

Best-matched resistance

R* = Vmax/Icap
Current and voltage capability are used together. A lower Pmax can broaden this point into a constant-power plateau.

High resistance

P = Vmax²/R ↓
Voltage is already at its ceiling. More resistance reduces current faster than resistance increases.

Transparent model documentation

Calculations & implementation

Every equation used by the model is listed below in execution order. All internal calculations use SI units and absolute temperature.

Model scope: zero-dimensional screening plus a steady axisymmetric finite-volume temperature field for a porous cylindrical envelope, optional gas gap, and enclosing wall. Preset ρ(T), Cp(T), and k(T) use piecewise-linear source data where available; marked fallback properties remain constant.

1 · Unit conversion & geometry

Electrical resistivity
ρe [Ω·m] = 0.01 · ρe [Ω·cm]
For µΩ·m input: ρe [Ω·cm] = 10−4 · value.
Void fraction and solid volume
Venv = Vnominal,   Vsolid = (1−φ)·Vnominal
φ = 0 is a solid rod. The nominal volume fixes the L × D envelope; φ only removes conducting solid (and mass) from it.
Nominal volume + aspect ratio
D = ∛(4Venv / π(L/D)),   L = (L/D)D
Electrical area
Aeff = fsπD²/4
Uniform axial pores and tortuosity τ = 1. Random foams generally require Aeff/τ and a measured effective conductivity.
Exposed surface & thermal length
As = πDL + πD²/2,   Lc = Venv/As
Internal pore area is excluded because pore topology is not provided.
Mass
m = ρmVsolid

2 · Electrical operating point

Temperature-dependent properties
y(T) = yi + (yi+1−yi)(T−Ti)/(Ti+1−Ti)
Piecewise-linear interpolation with endpoint clamping. For pure-metal fallback: ρ(T)=ρ20[1+α(T−20°C)].
Conductivity & resistance
σe(T) = 1/ρe(T),   R(T) = ρe(T)L/Aeff
Four current ceilings
II = Imax
IV = Vmax/R
IJ = JmaxA
IP = √(Pmax/R)
Selected current
I = min(II, IV, IJ, IP)
Equal minima are reported as simultaneous active constraints. In A-limited mode I = Iset and in V-limited mode I = Vset/R instead; the setpoint slider range is capped by the other limits at the target-temperature resistance, and any residual exceedance from the temperature dependence of ρ(T) is flagged rather than clamped.
Voltage, power & densities
Ve(T) = I(T)R(T),   P(T) = I(T)²R(T)
J = I/Aeff,   p‴ = P/Vsolid,   Psp = P/m
Design recommendation
R ∝ ρe(L/D)4/3,   Aeff ∝ (L/D)−2/3
L/D and ρe are searched over ±4 decades. Imax, Vmax, Pmax, and Jmax are applied at every candidate. The closest candidate delivering at least 99.5% of the maximum initial power is reported.

3 · Heating & target feasibility

Initial adiabatic ramp
(dT/dt)0 = P(Ta)/[mCp(Ta)]
Ideal adiabatic lower bound
tideal = max(0, Tt − Ta)/(dT/dt)0
Always shown. It ignores loss and property variation during the ramp, so it is not a predicted transient heating time.
Power required at target
Preq = max(0, Ploss(Tt))
Required electrical point
Vreq = √(PreqR),   Ireq = √(Preq/R)
Feasibility
Target feasible ⇔ P(Tt) ≥ Preq
Melting/decomposition check
Warn ⇔ Tss > Tmelt;   Vsafe = √(Ploss(Tmelt)R(Tmelt)),   Isafe = √(Ploss(Tmelt)/R(Tmelt))
Tmelt is each preset's melting, decomposition, or sublimation point (source noted per material). Vsafe and Isafe are the single-parameter Vmax or Imax ceiling that would hold Tss at Tmelt with everything else unchanged; lowering either one alone is sufficient.

4 · Heat loss & steady state

Element → wall
Ge→w = (Rgap+Rwall)−1 + (Grad,gap−1+Rwall)−1
Gas conduction and gray-surface gap radiation act in parallel; quartz conduction follows each path.
Wall → ambient
Gw→a = (Rair+Rh)−1 + Grad,wall + Gwall,end
Rair uses the same automatically scaled outside-air radius as the 60 × 60 map.
Wall temperature
Ge→w(T−Tw) = Gw→a(Tw−Ta)
Total heat loss
Ploss = Pside + Pend + ĊHe(Tout−Tin)
Steady-state temperature
Find Tss such that Ploss(Tss) = P(Tss)
Solved numerically by bracket expansion followed by 100 bisection iterations.

5 · Biot & uniformity screening

Enclosure-equivalent coefficient
heff = Ploss(Tt)/[As(Tt−Ta)]
Biot number
Bi = heffLc/k
Critical conductivity
kcrit = heffLc/Bilimit
Uniformity flag
Uniform-temperature screening passes when Bi ≤ Bilimit.

6 · Material-limit diagnostics

J-limit ramp ceiling
rJ,max = Jmax²ρe/(ρmCp)
Field at J-limit
Emax = Jmaxρe
Voltage across element at J-limit
VJ,max = EmaxL
Power-supply utilization
Power use = P/Pmax

7 · Axisymmetric 2D finite-volume model

Steady energy equation
(1/r)∂/∂r[kr∂T/∂r] + ∂/∂z[k∂T/∂z] + q‴ = 0
The display is fixed at 60 × 60 cells. The half-domain contains 30 radial × 60 axial annular volumes; element, gap, full-height wall, He, and surrounding-air widths are assigned automatically while region boundaries remain exact.
Exact annular cell geometry
VP = π(re²−rw²)Δz
Ae,w = 2πre,wΔz,   An,s = π(re²−rw²)
Interface conductance
GPN = Af/[δP/kP + δN/kN]
The series thermal resistance gives the distance-weighted harmonic conductivity across element–gap and gap–wall interfaces.
Cell balance
aPTP = ΣNGPNTN + q‴VP + ΣbGbTb
aP = ΣNGPN + ΣbGb
Axis boundary
∂T/∂r = 0 at r = 0
The west-face area is zero at the cylinder axis.
Outer wall loss
−k∇T·n = h(T−Ta) + εσSB(T⁴−Ta⁴)
hrad = εσSB(T+Ta)(T²+Ta²)
Electrical contact and bulk heat
Rc = ρc/Aeff,   Rtotal = Rbulk + 2Rc
Pbulk = I²Rbulk,   Pcontact = I²(2Rc)
Uniform porous-envelope source
q‴ = Pbulk/Venv
Using envelope volume guarantees Σq‴Vcell = Pbulk. The current 2D model does not resolve pore-scale current constriction.
Electrothermal iteration
T̄element → ρe(T̄) → Rbulk → I → Pbulk → q‴ → T(r,z)
The supply ceilings are recalculated during the temperature iteration. Local k(T) is evaluated cell by cell.
Convergence and energy closure
max|TPn+1−TPn| ≤ tolerance
closure = |Pbulk−Qboundary|/max(Pbulk,10−12)

Assumptions, exclusions & source hierarchy

Included
Uniform porous cylinder, enclosure-coupled 0D heat loss, temperature-dependent source-limited electrical operation, 2D radial/axial conduction, gas-gap conduction and radiation, wall and outside-air conduction, 50 sccm top-to-bottom He enthalpy advection, optional electrical contact resistance, three element-end boundary modes, target feasibility, and energy closure.
Excluded
Navier–Stokes velocity, pressure drop, gas-property variation with temperature, electrode temperature fields, lead loss, internal pore-scale convection/radiation, reaction heat, oxidation kinetics, thermal expansion, stress, phase change, sintering, anisotropy, pore-size distribution, pore-scale current hotspots, and cycling life.
Jmax caution
Mittal et al. report Jmax only for selected materials. Manufacturer-safe current density also depends on element size, atmosphere, surface load, terminals, and life target. Unreported presets use a visible screening assumption and must be replaced for engineering release.
Sources
Mittal et al., Chemical Engineering Journal 520 (2025) 166348 · NIST electrical resistivity compilation · Kanthal Super (MoSi₂) · Kanthal/Nikrothal alloys · Inconel 601 bulletin.

0D vs 2D vs experiment. The tables above compare the 0D screening model, which carries one lumped temperature for the whole element. The 2D columns below solve the same three cases as resolved fields, so the question they answer is whether the single number 0D reports is a temperature the element actually holds. The 2D solves are precomputed (each takes seconds) and regenerate with node tools/verification/crosscheck.mjs --write; the 0D column is computed live from the enclosure set on the 2D Thermal Map tab, so the two columns agree only while that enclosure is at its defaults.

Wismann's tube is the only case with a measured element temperature, and there the resolved field lands within 2% of it while the lumped model is 5% low — the 0D screen understates the temperature because it spreads the same power over an isothermal body. Every case carries an internal ΔT that 0D cannot represent at all, which is what the melting-point check on the Single Design tab is reading past: that check runs on the 0D Tss.
